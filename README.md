# Pokechat AI

Uma Pokédex conversacional em português para explorar informações sobre Pokémon com inteligência artificial.

O projeto está começando do zero. A proposta é usar o universo Pokémon para aprender e experimentar com aplicações de IA.

## Ideia inicial

Construir um chat em que seja possível fazer perguntas sobre Pokémon. O escopo e as funcionalidades serão definidos durante o desenvolvimento.

## Estado atual

Ainda não há código, dependências ou configurações da aplicação. Stack, arquitetura e próximos passos estão em aberto.

As instruções de instalação, execução e testes serão adicionadas conforme a implementação avançar.
